# Conceitos Básicos de Programação Orientada a Objetos (POO)

## Objetivo
Apresentar de forma clara, prática e didática os fundamentos da Programação Orientada a Objetos (POO), permitindo a compreensão de seus quatro pilares fundamentais (abstração, encapsulamento, herança e polimorfismo) e como aplicá-los no desenvolvimento de software.

## Público-alvo
Este guia foi criado para estudantes de computação, desenvolvedores iniciantes e entusiastas de programação que desejam migrar do paradigma procedural ou consolidar a base teórica e prática de POO.

## Pré-requisitos
Para aproveitar ao máximo o conteúdo, é recomendado possuir:
- Lógica de programação básica (estruturas condicionais, laços de repetição e variáveis).
- Um editor de código configurado (ex.: VS Code, Neovim) e um compilador/runtime da linguagem de sua preferência.
- Noções básicas de terminal e versionamento de código com Git.

## Estrutura do guia
O material é dividido em módulos modulares e sequenciais dentro do diretório `docs/`:

* **`docs/01-introducao.md`**: Visão geral sobre paradigmas de programação e o surgimento da POO.
* **`docs/02-conceitos.md`**: Explicação aprofundada dos pilares (Classes, Objetos, Encapsulamento, Herança e Polimorfismo).
* **`docs/03-exercicios.md`**: Desafios práticos e fixação de lógica orientada a objetos.
* **`docs/04-referencias.md`**: Livros, artigos e documentações complementares para aprofundamento.
* **`exemplos/`**: Códigos comentados para consulta direta.

## Como navegar
Recomenda-se seguir a ordem sequencial dos documentos:
1. Inicie pela **Introdução (`01-introducao.md`)** para ambientar o conceito.
2. Prossiga para os **Conceitos Fundamentais (`02-conceitos.md`)** e analise os códigos em conjunto com a pasta `exemplos/`.
3. Pratique resolvendo as questões em **Exercícios (`03-exercicios.md`)**.
4. Consulte as **Referências (`04-referencias.md`)** para expandir seus estudos.
